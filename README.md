# Breast Cancer Detection Using Machine Learning

## Project Overview
This project uses Machine Learning to classify breast cancer cases as **Malignant** or **Benign** using the Breast Cancer Wisconsin Diagnostic dataset.

## Model Used
- Logistic Regression
- StandardScaler for feature scaling
- NumPy for prediction calculations

## Technologies Used
- Python
- NumPy
- Streamlit
- Scikit-learn (for model training)

## Features
- User-friendly Streamlit interface
- 30 input features
- Malignant or Benign prediction
- Prediction probability display

## How to Run

1. Clone or download this repository.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Run the application:

   `streamlit run app.py`

## Disclaimer
This application is developed for educational purposes only. It is not intended for medical diagnosis or clinical decision-making.
